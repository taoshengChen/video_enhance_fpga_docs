# 寄存器全量大师 (Reg Map Master)

本技能直接以 Markdown 文档为源，自动化维护第 6 章的所有寄存器内容。

## 核心功能

1.  **自动地址刷新**：按 `6.2` 章节出现的顺序，自动将地址从 `0x00` 开始依次递增。
2.  **保留位对齐**：自动检测 `0-15` 比特中缺失的位域，并在位域表中插入“保留”行。
3.  **默认值合成**：解析位域复位值，合成 16-bit 默认值（十六进制），并更新至摘要表。
4.  **智能同步**：自动刷新 `6.1` 摘要表，包括名称、类型、默认值及符合项目偏好的锚点链接。


## 使用方法

### 指令调用
`python3 scripts/reg_map_md_master.py <path_to_md>`

### 应用场景示例

#### 场景 A：添加/删除/移动寄存器
1. 在 `6.2` 章节直接增加、删除或拖动整个寄存器子章节。
2. 运行脚本。
3. 脚本将自动：
   - 重新分配所有寄存器地址（从 `0x00` 连续递增）。
   - 对 `### 6.2.x` 重新编号。
   - 刷新 `6.1 寄存器摘要` 表。

#### 场景 B：修改位域参数
1. 在 `6.2.x` 的表格中修改位域范围或复位值。
2. 运行脚本。
3. 脚本将自动：
   - 重新计算该寄存器的 16-bit 默认值并同步到摘要表。
   - 自动补齐因修改范围导致的位域 Gap。

## 约束与校验
- **位域重叠**：若检测到比特位重叠，脚本将报错并停止，保护设计逻辑。
- **位宽溢出**：若复位值超过位域定义的宽度，将发出警告提示。
