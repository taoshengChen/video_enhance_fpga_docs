# Smart Anchor Sync & Repair

此技能专门解决 Markdown 内部跳转链接因标题内容修改而失效的问题。

## 工作原理

1. **识别失效链接**: 脚本扫描文档中的所有内部链接（如 `[描述](###章节名)`），并检查当前文档中是否存在对应的标题。
2. **模糊语义匹配**: 如果链接失效，脚本会剥离链接中的数字序号（如 `3.4.1`），利用字符串相似度算法在现有标题中寻找语义最接近的目标。
3. **结构索引校验**: 如果存在多个相似标题，脚本会参考其在目录结构中的相对位置进行二次校验。
4. **全量同步**: 自动更新所有引用的位置。

## 链接规范

- **无空格格式**: 锚点链接必须采用 `[Link Text](#+Title)` 格式，其中 `#` 与标题文本之间不能有空格。
  - 正确: `[SPI时序要求](##4.6 SPI时序要求)`
  - 错误: `[SPI时序要求](## 4.6 SPI时序要求)`

## 使用指令
`python3 scripts/repair_anchors.py <path_to_md>`
